Set up offline attendance

In the QRoll teacher console, open ⚙ Settings → Offline Quick Attendance and tap Enable on this device. Copy the pairing code it shows and paste it below. The code is shown once.

Pairing stores a token for this app only. It can read your class lists and submit attendance — nothing else. It cannot open the console, read marks or change settings, and you can revoke it from the console at any time. Your 6-digit PIN is not stored here.
